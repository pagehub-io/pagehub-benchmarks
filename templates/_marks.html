{# Aggregate-figure marking, shared by every page that publishes a run total. A run's per-attempt caveats can make the run's OWN totals a lower bound rather than a measurement: see RUN_TOTAL_LOWER_BOUND_CAVEATS in tools/build_site.py for which values do that and why. The caveats these macros NAME are only the ones that shorten the total — a neutral caveat in the same run is filtered out before it reaches here (test_a_neutral_caveat_is_never_named_as_a_reason_a_total_is_short). Marking the attempt row alone left the headline, the index's cost table, the benchmark page and the theory comparison all rendering the short figure unmarked (review round 12), so the marking lives here and every surface imports it. Visual language matches the per-attempt marker already on the run page: a hoverable ⚠ naming the reason, plus a ≥ on the figure itself so the direction of the error is readable without hovering. #} {% macro lb_title(caveats) %}This run's totals are a lower bound, not a measurement: it spent tokens the harness could not attribute to any attempt ({{ caveats|join(', ') }}), so the real figure is higher by an unknown amount. See the per-attempt table on the run page.{% endmacro %} {% macro warn(caveats) %}⚠{% endmacro %} {% macro cost(r) %}{% if r.totals_are_lower_bound %}≥${{ '%.4f' % r.cost_usd }} {{ warn(r.totals_lower_bound_caveats) }}{% else %}${{ '%.4f' % r.cost_usd }}{% endif %}{% endmacro %} {# The token columns carry the ≥ but not the triangle — three more triangles per row is noise — so the explanation rides on the number's own title instead. Without it, index.html and benchmark.html rendered a bare ≥3,199 whose only gloss was the tooltip on the cost cell further along the row (review round 13). #} {% macro count(r, value) %}{% if r.totals_are_lower_bound %}≥{{ '{:,}'.format(value) }}{% else %}{{ '{:,}'.format(value) }}{% endif %}{% endmacro %} {% macro metric(display, lower_bound, caveats) %}{% if lower_bound %}≥{{ display }} {{ warn(caveats) }}{% else %}{{ display }}{% endif %}{% endmacro %}
